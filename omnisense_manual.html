OmniSense AI Manual

Complete reference guide for standard interface controls, voice commands, and spatial hand gestures.

💻 Dashboard Interface Controls

Active

Toggle Camera (Video Icon)

Activates background camera feed to provide "vision" and environmental context to the AI.

Active

Toggle Microphone (Mic Icon)

Starts the continuous Speech-To-Text engine. The system will actively listen for commands.

Active

Spawn Object (+ Button)

Manually generates a random 3D primitive geometry into your current spatial view.

Active

Text Input

If voice input is unavailable, use the chat input box to send direct spatial commands.

🎙️ Voice Commands

Requires the Microphone to be actively toggled ON.

Active

"Spawn a box" / "Spawn a cube"

Instantly generates a 3D box entity at a random nearby coordinate in space.

Active

"Spawn a sphere" / "Spawn a ball"

Instantly generates an interactive 3D orb entity in your spatial environment.

Upcoming

"Delete that"

Instructs the AI to delete the object you are currently looking at or pointing to.

Upcoming

"Make it bigger"

Context-aware command to increase the scale of the nearest spatial object.

🖐️ Spatial Hand Gestures (WebXR)

The following gestures are mapped for the upcoming WebXR / Vision integration. Hand tracking must be enabled via device capabilities.

Upcoming Phase 2

Pinch & Drag

Pinch your index finger and thumb over an object, then move your hand to reposition the object in 3D space.

Upcoming Phase 2

Two-Handed Expand

Pinch opposite corners of an object with both hands and pull apart to uniformly scale up the object size.

Upcoming Phase 2

Swipe Away

A fast sweeping motion over a 3D object to dismiss or delete it from the environment.

Upcoming Phase 2

Open Palm (Halt)

Raise an open palm to the camera to pause all active AI listening and recording processes temporarily.
